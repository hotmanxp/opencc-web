## 微信实例的「助手人格设定」(SOUL.md / IDENTITY.md / USER.md)

把 WorkBuddy 那套人格设定逻辑搬进 zai,**只作用于微信通道**。

- 新增 `packages/zai/src/server/services/weixinBot/weixinPersona.ts`
  - 目录优先级:`ZAI_WEIXIN_PERSONA_DIR`(终局覆盖,不回退)→ `<ZAI_DATA_DIR>/weixin/persona/` → `~/.workbuddy/`(WorkBuddy 既有目录,开箱即用)。
  - 判定"能读出至少一个非空文件"才采用;空目录/空文件继续回退。这是刻意的 —— 只在 env 里写个路径指错时不静默换目录。
  - 缓存用 **mtime+size+ino 签名**(不是 weixinMemory 的会话级冻结快照):人格是给人手改的,冻结到轮转才生效会变成"改完没反应"的高频困惑。签名没变复用同一字符串对象(逐字节稳定,不扰动 prompt cache),变了立即重读。
  - 截断保护:单文件 8KB、合计 20KB,按 Buffer 字节切(不劈多字节字符)。
  - `renderPersonaBlock()` 输出 `<identity-context>` 块,块内指令文字全英文(仓库硬约束),文件正文原样透传。
- 注入点:`weixinInboundBridge.renderWeixinPrompt(msg, media, memory, persona)`,人格块**置顶**(固定内容在前、动态 env 在后)。`_deliverOnce` 与 `replayPending` 两个调用点都加载。
- 判定"只针对微信实例"的依据:`renderWeixinPrompt` 只被 `weixinInboundBridge` 调用,而 bridge 只在 `app=weixin` 专用实例上收到消息。Web 端会话不经这条路径。

测试:`test/server/weixinBot/weixinPersona.test.ts`(8 例,vi.mock node:os homedir 保证 `~/.workbuddy` 回退分支确定性)+ bridge 加 2 例(置顶注入 / 无人格不注入)。bridge 测试的 `beforeEach` 把 `ZAI_WEIXIN_PERSONA_DIR` 指向不存在的路径,避免真实 `~/.workbuddy` 泄漏进断言。33 例全过,`tsc -b --noEmit` 干净。

真实环境验证:本机 `~/.workbuddy` 的 SOUL/IDENTITY/USER 被正确识别,渲染 4668B。

### 补人格块的「维护指引」(同日,用户确认)

起因:用户问"提示词里 LLM 知道人格文件路径吗?有没有东西告诉它怎么改?" 查完结论 ——
**路径知道**(`renderPersonaBlock` 每个文件输出 `Path: <绝对路径>`),但**怎么改几乎没说**:
只有一句 `You may maintain these files yourself...`,而隔壁 `<weixin-memory>` 的记忆维护段
把"何时写/写什么格式/用哪个工具/存哪/何时生效"全交代了。后果:模型有能力改(默认
`permissions.defaultMode = 'bypassPermissions'` + `Write`/`Edit`/`Bash(*)` 在 allow 里)却
几乎不会主动改,也不知道边界。

据此扩写了 `renderPersonaBlock()` 的指令段(全英文),逐条钉住:
- 只有 `SOUL.md / IDENTITY.md / USER.md` 可维护,别新建、别拿它们当笔记/待办/记忆载体;
- 仅在用户明确要求调整性格/语气/称呼时才改,意图含糊先问一句,否则本轮照办不动文件;
- **`USER.md` 与 `<weixin-memory>` 长期记忆文件的分工写清楚** —— 用户让记住的事实走记忆文件,
  别在 `USER.md` 里重复(不写这条模型会两边乱写);
- 上限 8KB/文件、20KB 合计(文案用 `PERSONA_FILE_MAX_BYTES` / `PERSONA_TOTAL_MAX_BYTES` 插值,改常量不会漂移);
- 改完一句话告知用户(文件在宿主机,微信里看不见);下一条消息即生效,**不许跟用户说要重启**;
- 末尾注明本块每条消息从磁盘重建,读到的是当前内容。

测试:`weixinPersona.test.ts` 加一例断言上述要点(含路径/常量/生效时机),防被人顺手删掉
没人发现。200 例全过,`tsc -b --noEmit` 干净。真机渲染 5839B(指引段约 1.1KB)。
